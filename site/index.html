光纤传感 × 集成电路

从集成制造、传感原理与封装测试三个角度，研究如何把光纤中的波长、相位和光谱变化，转化为可校准、可测试、可扩展的电学数据。

研究启动稿 · 尚无芯片或实验结果
01 · BASELINE

普通 FBG

以成熟的温度、应变和振动测量作为验证基线，回答集成读出是否真正“测对”。

02 · CORE

TFBG 折射率

研究能否用集成滤波、光电探测和 CMOS 特征提取，减少对高分辨率光谱仪的依赖。

03 · HORIZON

DAS / 感知通信

探索分布式传感、光互连监测以及通信与感知共享光纤资源的条件和代价。

光纤敏感元件 → PIC 滤波 / 干涉 / 波分映射 → PD → TIA / AFE → ADC → 数字解调与校准

证据边界

本项目是公开论文与工程问题的研究框架。硅光解调论文不等于量产产品，工业解调仪不等于芯片级融合，远期应用不等于当前成果。

所有关键主张将区分来源事实、作者推导、研究假设和待核对问题。
