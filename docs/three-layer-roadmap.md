# 三层技术路线

本页保留三层技术结构；跨方向的完整候选课题、优先级和证据缺口见 [`three-route-research-map.md`](three-route-research-map.md)。

## 第一层：集成制造

研究对象不是单一工艺，而是异质边界：

```text
光纤敏感区
↕ 光纤端面、边缘耦合、光栅耦合或中间光学结构
硅光 / SiN / InP 光子芯片
↕ PD、键合、互连和热管理
CMOS 模拟与数字芯片
↕ 基板、封装、连接器和环境暴露窗口
应用结构或被测封装
```

需验证的问题包括耦合损耗、对准容差、温度预算、污染、机械应力、材料兼容、可替换性和良率。

## 第二层：传感原理与读出

主线不是“光纤直接输出电压”，而是逐级转换：

```text
温度 / 应变 / 折射率
→ 有效折射率或光栅周期变化
→ 波长、相位、强度或光谱形状变化
→ PIC 滤波、干涉或波分映射
→ 光电流
→ TIA / PGA / ADC
→ 数字解调、参考校准和状态记录
```

每一级都可能贡献噪声、漂移或非线性，不能只优化其中一个器件。

同时保留一条待验证的 CPO 黑盒读出分支：

```text
主动电测试序列
→ CPO / 硅光发射机
→ 功能化 TFBG 或其他敏感光纤段
→ CPO / 硅光接收机
→ 波形、软判决、均衡器状态、pre-FEC BER 和错误结构
→ 电学指纹数据库与传感状态反演
```

这条分支的优先问题不是设计新 CPO，而是验证已有收发链的观测量是否足够连续、可访问、可重复且可与温度、弯折、偏振和老化区分。

## 第三层：封装测试与系统应用

候选观测对象包括：

- 封装热点与热循环；
- 芯片、基板或光学组件的应变和翘曲；
- 光纤—芯片耦合位置的机械漂移；
- 振动、冲击和长期疲劳；
- 光互连链路附近的温度与结构状态；
- 同一光纤上通信与分布式感知的资源共享。

这些均为应用假设。后续必须与电学温度传感器、应变计、热像或商用光纤解调仪建立对照，才能评价新增价值。
