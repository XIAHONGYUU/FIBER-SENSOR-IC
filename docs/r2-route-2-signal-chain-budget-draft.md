# R2 路线二草案：光学—电学信号链与误差预算

**版本：** v0.1 R2 草案

**日期：** 2026-10-13

**状态：** 公开研究草案 / 参数待实测 / 尚无系统实验结果

**适用范围：** 普通 FBG 验证基线、TFBG 折射率主线，以及后续功能化光纤读出

## 1. 文档目的与证据边界

本草案把路线二拆成两种可比较、可先后推进的读出架构：

1. **专用解调链：** 光源 → FBG/TFBG → PIC 滤波或干涉网络 → PD → TIA → ADC → 数字反演；
2. **既有收发机黑盒：** 可控电输入 → 可插拔光模块/CPO/相干收发机 → 功能化光纤 → 接收机 → 连续电学特征、DSP 状态和链路遥测。

两条架构共享同一个研究问题：

> 在温度、应变、偏振、光功率、连接损耗和器件漂移同时存在时，能否把目标光纤状态稳定地映射为可校准、可复现并可反演的电学特征？

本文中的数值均应在后续器件选型或实测后填写。本文不预设灵敏度、分辨率、动态范围、功耗或误差指标，也不声称现有商用 CPO 已开放所需的原始 ADC、软判决或均衡器数据。

已有证据只支持以下邻近事实：硅光 AWG、MZI、微环、微干涉仪和片上探测器已经用于 FBG/TFBG 解调研究；较低分辨率的 TFBG 光谱可以结合数字算法提取特征；通信与感知可以在限定条件下共享光纤资源；标准化收发模块管理接口定义了部分性能监测量。这些证据不等于本文任一候选系统已经完成。[E-002—E-007、E-013—E-021、E-034—E-036](../evidence/evidence-ledger.csv)

## 2. 统一系统模型

把目标传感状态记为 `x`，干扰状态记为 `q`，可控输入记为 `u`，光学响应记为 `o`，连续电学观测记为 `y`，DSP/遥测记为 `z`：

```text
q = {温度 T，应变 ε，偏振 p，弯折 b，连接损耗 c，老化 a，批次 k}

u ──> 发射/光源 ──> 敏感光纤 H(x,q) ──> 光学状态 o
                                               ↓
                                光电转换与接收链 G(o,q,φ)
                                               ↓
                               连续电学观测 y，DSP/遥测 z
```

其中 `φ` 表示光源、PIC、AFE、ADC、DSP、自适应环路和校准的内部状态。统一前向模型为：

```text
o = H(u, x, q)
y, z = G(o, q, φ) + n
x_hat = f(u, y, z, reference, calibration)
```

`n` 是随机噪声与未建模扰动。任何“折射率反演”结论都必须同时给出：测得的 `u/y/z`、参考通道、标定域、留出测试条件和无法区分的干扰状态。

## 3. 架构 A：专用 PIC—PD—TIA—ADC 解调

### 3.1 候选信号链

```text
稳定宽带光源 / 可调激光 / 多波长光源
                    ↓
功率监测 + 偏振准备 + 温度记录
                    ↓
普通 FBG（验证基线）或 TFBG（主线）
                    ↓
环行器/分束/耦合与参考光路
                    ↓
AWG / MZI / 微环 / 边缘滤波器 / 可编程 PIC
                    ↓
单路、差分或多路 PD
                    ↓
TIA → PGA/滤波 → ADC
                    ↓
比值/质心/差分面积/模型反演 + 置信度
```

硅光 AWG、MZI、微环与片上微干涉仪已分别用于 FBG 或 TFBG 解调研究，证明多种“光谱到少量电通道”的实现路径存在，但相关论文并不证明量产良率、长期稳定性或 CMOS 单片集成已经解决。[集成 WDM FBG 解调器](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-37-18-4770)、[SOI AWG TFBG 解调](https://opg.optica.org/ol/abstract.cfm?uri=ol-33-22-2647)、[SOI 微环 FBG 解调器](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-40-15-5328)、[片上微干涉仪 FBG 解调器](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-41-13-4397)

### 3.2 可控输入 `u_A`

| 输入 | 可控字段 | 设计目的 | 尚待验证 |
|---|---|---|---|
| 光源 | 波长/波段、功率、扫速、占空比 | 扫描或定位敏感谱段 | 光源漂移是否小于目标变化 |
| PIC 调谐 | 加热器电流、电压、相位码 | 移动滤波器或选择投影 | 热串扰、迟滞和功耗 |
| 偏振 | SOP、偏振切换序列 | 分离 TFBG 偏振响应 | 封装后是否可重复 |
| 校准激励 | 已知衰减、参考波长、暗态 | 估计增益、零点与非线性 | 校准能否覆盖工作温度 |

### 3.3 光学状态 `o_A`

至少记录以下中间量，而不只记录最终折射率：

- 传感器反射或透射谱 `S(λ)`；
- Bragg 峰、包层模、包络、谱面积、偏振差分等候选特征；
- 光源功率和参考端功率；
- PIC 各通道传递函数 `F_i(λ,T_chip)`；
- 光路插入损耗、反射和串扰；
- 有参考仪器时的波长或频谱真值。

TFBG 的差分面积、包络导数和正交偏振差分均有论文先例，但它们只构成候选观测量，不能预设对所有涂层、目标物和环境都有效。[差分面积法](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-37-18-4531)、[包络导数法](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-41-13-4123)、[正交偏振差分](https://opg.optica.org/ao/abstract.cfm?uri=ao-50-22-4257)

### 3.4 连续电学观测 `y_A` 与数字输出 `z_A`

| 层级 | 连续观测/输出 | 记录要求 |
|---|---|---|
| PD | 每通道光电流、暗电流、参考 PD 电流 | 原始值、量程、积分时间、温度 |
| TIA/PGA | 输出幅度、噪声统计、增益档、饱和标记 | 不允许只保留归一化结果 |
| ADC | 原始码、均值、方差、直方图、溢出码 | ADC 配置、参考电压、采样同步 |
| 数字特征 | 比值、差分、质心、面积、投影向量 | 算法版本和校准版本 |
| 估计结果 | `x_hat`、置信区间、域外/异常标记 | 同时保留真值和残差 |

### 3.5 参考通道

最低配置应包含：

- **源功率参考：** 在传感光纤前分光，抑制光源功率漂移；
- **非敏感参考光纤：** 与敏感光纤经历相似温度、弯折和连接路径，但无功能层或无目标暴露；
- **PIC 内部参考：** 不经过敏感光谱的旁路滤波通道，用于估计 PIC/PD/AFE 漂移；
- **外部真值：** 初期使用可追溯光谱仪、功率计及折射率/浓度/温度参考；
- **暗参考：** 周期性遮光或关闭光源，以测量暗电流和电子偏置。

参考结构必须与“被补偿的扰动”一一对应；单一功率参考不能同时证明温度、偏振和涂层老化已经被消除。

## 4. 架构 B：可插拔/CPO/相干收发机黑盒复用

### 4.1 候选信号链

```text
FPGA / BERT / ASIC：可控电测试序列 u_B(t)
                    ↓
可插拔光模块 / 硅光收发机 / CPO Tx
                    ↓
普通光纤 + 可替换功能化 FBG/TFBG 段
                    ↓
可插拔光模块 / CPO Rx / 相干接收机
                    ↓
模拟波形 y_B + DSP/链路遥测 z_B
                    ↓
电学指纹数据库 → 状态反演与置信度
```

OIF CPO 框架支持把光引擎视为 ASIC 与光信号间的转换单元，但不保证具体 CPO 平台开放内部观测量。[OIF Co-Packaging Framework](https://www.oiforum.com/wp-content/uploads/OIF-Co-Packaging-FD-01.0.pdf) CMIS/C-CMIS 定义了部分接收和链路性能监测机制，但原始 ADC、LLR、均衡器抽头等是否可读，必须逐平台核验。[CMIS 5.1](https://www.oiforum.com/wp-content/uploads/CMIS5p1_Third_Party_Spec.pdf)、[OIF C-CMIS 1.0](https://www.oiforum.com/wp-content/uploads/OIF-C-CMIS-01.0.pdf)

相干收发机用于现场光纤偏振/环境感知已有实验先例，这支持“复用通信接收机内部连续状态”的方法邻近性；它不证明局部功能化 TFBG 能唯一反演折射率。[现场相干收发机偏振感知](https://www.nature.com/articles/s44172-024-00237-w)、[相干检测环境感知](https://opg.optica.org/jlt/abstract.cfm?uri=jlt-41-11-3350)

### 4.2 可控输入 `u_B`

| 输入维度 | 候选设置 | 可能增加的信息 | 通信约束 |
|---|---|---|---|
| 码型 | PRBS 阶数、固定帧、训练序列 | 信道记忆、模式相关误差 | 测试窗口和业务兼容 |
| 符号统计 | PAM4 电平概率、跳变密度、连码长度 | 电平非线性、带宽、基线效应 | 平均功率和编码限制 |
| 功率 | 小幅、多级发射功率激励 | 损耗斜率、非线性 | 眼安全、链路预算、激光限制 |
| 频率 | 导频、多音或子载波 | 频响变化 | 频谱掩模和业务代价 |
| 波长/lane | WDM lane 选择、可调波长 | 对敏感谱的稀疏采样 | lane 差异需校准 |
| 偏振 | 双偏振训练或可控 SOP | 偏振相关响应 | 平台可能不开放控制 |

主动激励的设计目标可以写成“最大化目标状态与干扰状态的可分性或 Fisher 信息”，但实际优化目标、通信代价和约束均须由实验定义，不能在无数据时声称灵敏度提高。

### 4.3 连续电学观测 `y_B`

- Rx 光功率或 PD 电流；
- TIA/AGC/PGA 增益与输出幅度；
- ADC 采样、PAM4 电平中心和方差；
- 眼高、眼宽、交叉点、抖动统计；
- 相干 I/Q、两偏振状态、相位和频偏；
- 若仅能访问汇总值，则记录其窗口、刷新率、量化步长和饱和条件。

这些字段是**候选访问清单**，不是商用模块的通用能力声明。

### 4.4 DSP 与遥测 `z_B`

| 类别 | 候选字段 | 解释边界 |
|---|---|---|
| 软判决 | LLR/置信度分布、符号混淆矩阵 | 需证明与物理扰动的稳定关系 |
| 均衡 | CTLE/FFE/DFE 抽头、阈值、时钟相位 | 自适应算法可能补偿并隐藏传感变化 |
| 链路质量 | eSNR、Q、pre-FEC BER、纠错计数 | 是聚合结果，不对应唯一物理原因 |
| 错误结构 | 电平转移、码型相关、突发长度、lane 分布 | 需排除接收机实现特有伪影 |
| 系统状态 | 温度、激光偏置、Tx/Rx 功率、告警 | 用于协变量，不应直接当作目标真值 |
| 阈值事件 | lane degrade、link down | 只能作为末级报警，不是连续传感主输出 |

### 4.5 参考通道与双工作模式

推荐至少保留一条非敏感参考 lane，并设置两种采集模式：

1. **跟踪模式：** 保持正常 AGC、均衡、CDR 和 FEC；记录它们的控制量，评估真实运行中的可观测性；
2. **冻结/校准模式：** 在受控短窗口冻结允许冻结的增益或均衡参数，发送固定训练序列，获得跨时刻可比的响应。

如果平台无法读取控制量，也不能进入冻结/校准模式，应把这种不可访问性记为架构风险，而不是用最终 BER 替代全部连续信息。

## 5. 参数化信号与误差预算

### 5.1 公共预算变量

| 类别 | 字段 | 记号/单位 | 来源状态 |
|---|---|---|---|
| 目标响应 | 目标量范围、光谱/损耗响应斜率、滞后、恢复时间 | `X_range`, `∂S/∂x`, `τ_rec` | 待传感器实测 |
| 光源 | 功率、波长/频率稳定度、RIN、线宽 | `P_src`, `σ_λsrc`, `RIN` | 待器件规格+实测 |
| 光路 | 固定损耗、目标引起变化、反射、偏振损耗 | `L_0`, `ΔL_x`, `RL`, `PDL` | 待实测 |
| 接收 | 响应度、暗电流、输入范围、带宽 | `R_PD`, `I_dark`, `I_min/max`, `B` | 待器件规格+实测 |
| AFE | 增益、输入等效噪声、线性误差、漂移 | `G_TIA`, `i_n`, `e_lin`, `dG/dT` | 待设计+实测 |
| ADC | 满量程、ENOB、采样率、参考漂移、同步误差 | `V_FS`, `ENOB`, `f_s`, `dV_ref/dT` | 待选型+实测 |
| 数字处理 | 窗口、延迟、偏差、方差、域外检测 | `N`, `t_lat`, `bias_f`, `var_f` | 待算法验证 |
| 环境 | 温度、应变、偏振、弯折、连接、老化范围 | `Q_domain` | 待应用场景定义 |

### 5.2 静态链路与动态范围

架构 A 的第 `i` 路一阶电流模型可写为：

```text
I_i(x,q) = R_PD,i · ∫ P_src(λ) · H_sensor(λ;x,q)
                    · H_path(λ;q) · F_i(λ;q) dλ + I_dark,i
V_i = G_TIA,i · I_i + V_offset,i
```

架构 B 的接收功率预算可写为：

```text
P_rx = P_tx - L_fixed - L_sensor(x,q) - L_margin          [dB 域]
```

必须同时满足：

```text
下限：目标状态产生的最小可用电学变化 > 预先定义的检测门限
上限：所有校准和干扰状态下 PD/TIA/ADC 不饱和，通信链路不过载
```

动态范围表至少填写：正常基线、目标最小/最大状态、最坏温度、连接损耗、弯折、老化余量、启动瞬态及恢复状态。`L_margin` 只能在链路和传感实验后确定，不能先验填成“行业典型值”。

### 5.3 随机噪声预算

把第 `i` 路输入等效方差参数化为：

```text
σ_i² = σ_source² + σ_shot² + σ_dark² + σ_TIA²
     + σ_ADC² + σ_crosstalk² + σ_algorithm² + σ_unmodeled²
```

若使用差分或比值，必须保留协方差：

```text
Σ_y = Cov([y_1, y_2, ..., y_m])
Var(g(y)) ≈ J_g · Σ_y · J_g^T
```

源功率、温度和时钟等共模噪声不能按“各通道独立”简单平方和。应通过同步原始数据估计协方差，并分别报告单次采样、平均后和长期 Allan/漂移统计。

### 5.4 漂移与系统误差预算

| 漂移源 | 观测方式 | 分离/补偿候选 | 未补偿时的判据 |
|---|---|---|---|
| 光源功率/波长 | 源参考 PD、波长参考 | 比值、周期校准 | 与目标响应同量级则不可忽略 |
| PIC 热漂移 | 片温、参考滤波通道 | 热控、标定面 | 超出标定域则域外报警 |
| PD/TIA/ADC 增益 | 暗态、已知光阶跃、内部参考 | 增益/零点校准 | 不能只靠算法吸收 |
| 传感器/涂层老化 | 重复标准液/已知状态 | 批次参数、寿命模型 | 不可恢复基线漂移需重构 |
| 连接器/弯折 | 参考 lane、反射/功率监测 | 差分和安装规范 | 与目标不可分则停止 |
| 接收 DSP 自适应 | 抽头、阈值、AGC 状态 | 记录控制量或冻结窗口 | 不可访问且隐藏变化则黑盒路线降级 |

总误差不应只给单一均方根值。至少分别报告：随机重复性、标定偏差、温度交叉敏感、批次差、时间漂移和模型泛化误差。

### 5.5 反演误差与可辨识性

局部线性化可写为：

```text
Δr = J_x · Δx + J_q · Δq + n
```

其中 `r` 是选定电学特征向量。预算必须填写：

- `J_x`：对目标状态的响应；
- `J_q`：对温度、应变、偏振、弯折、连接和内部控制状态的响应；
- 特征噪声协方差 `Σ_r`；
- 不同状态下 `J=[J_x J_q]` 的秩、条件数或等价可分性指标；
- 目标状态间最小距离与类内/批内方差；
- 标定域、插值域和明确禁止外推的域。

如果存在 `Δx ≠ 0` 与某组 `Δq` 产生统计上不可区分的 `Δr`，则目标量对当前激励和观测**不可辨识**。此时应增加波长、偏振、参考通道或主动激励，而不是只增加模型复杂度。

## 6. 最小验证序列

### M0：数据访问与可校准性预检

- 列出候选硬件可实际读取和控制的每个 `u/y/z/φ` 字段；
- 测量空载、暗态、已知衰减和已知功率阶跃；
- 核验原始值、刷新率、量化步长、饱和、自动增益和日志时间戳；
- 结果：形成平台能力表，不涉及传感性能结论。

### M1：普通 FBG 可追溯基线

- 使用普通 FBG 和温控/应变真值；
- 专用链与商用光谱/解调仪同步采集；黑盒链使用固定训练序列同步采集；
- 独立注入光功率、连接损耗、温度和弯折；
- 结果：确认连续电学可观测性、量程、重复性和主要混淆项。

### M2：未功能化 TFBG 折射率基线

- 使用标准折射率介质或其他可追溯折射率真值；
- 同步记录完整光谱、偏振、温度、参考 lane 和电学特征；
- 比较单一功率、少通道 PIC 特征、黑盒遥测和可访问软信息；
- 结果：判断是否存在不依赖完全掉线的连续、可恢复映射。

### M3：主动激励与功能层

- 只有 M2 通过后，比较码型、功率、波长/lane 或 PIC 调谐激励；
- 再加入功能化涂层和目标物/非目标物；
- 使用跨温度、跨时间、跨传感头的留出测试；
- 结果：量化主动激励相对固定输入的增益，并验证选择性是否来自功能层而非偶然相关。

## 7. 预注册通过与停止判据

所有数值阈值应在观察盲测结果前，由目标应用和参考仪器能力共同确定。

### 7.1 最小通过条件

1. 在不触发 PD/TIA/ADC 饱和或通信 link down 的区间内，至少一种原始或低阶电学特征随目标状态连续、可重复、可恢复变化；
2. 目标响应在独立批次中高于预注册的检测门限，并给出随机噪声、漂移和置信区间；
3. 在温度、应变、偏振、弯折和连接扰动测试中，目标量仍可辨识，或明确限定可用域；
4. 外部真值与反演结果在留出数据上满足预注册误差，而不只是训练集拟合；
5. 参考通道确实减少某项已测漂移，并给出前后对照；
6. 若宣称主动激励有价值，必须在相同测试预算和独立数据上优于固定输入基线。

### 7.2 停止或重构条件

- 只能观察到链路通断，无法获得连续前兆；
- 目标状态与至少一种现实干扰在可访问特征中不可区分；
- 固定插损、反射、PDL 或涂层老化使链路/动态范围预算不可闭合；
- 黑盒平台的自动控制隐藏响应且其状态既不可读也不可冻结；
- PIC 热漂移、通道差异或电子偏置超过目标响应且参考通道无效；
- 反演只在同一传感头、同一批次或同一天成立；
- 增加模型复杂度只能改善训练集，不能改善留出测试；
- 主动激励对通信的代价高于可测的灵敏度或选择性收益。

停止某一架构不等于停止整个路线：黑盒访问失败可以转向专用链；专用 PIC 预算不闭合可以先用黑盒平台验证传感信息是否存在。

## 8. 两架构选择门

### Gate 0：先用仪器建立真值

无论选择哪条架构，均先用普通 FBG/TFBG 与外部参考仪器建立 `x → 光学响应` 的基线。如果光学响应本身不可重复或不可区分，停止读出芯片/黑盒优化。

### Gate 1：黑盒访问门

优先选择架构 B 的条件：

- 能控制至少一种稳定测试输入；
- 能读取原始或近原始连续特征，而非只有 link up/down；
- 能记录关键自适应控制状态，或提供受控校准窗口；
- 固定插损和反射仍在链路预算内；
- 数据接口允许自动化、同步和重复采集。

若以上核心条件不满足，不应把“商用黑盒”作为定量主路线；可将其保留为报警或应用验证平台。

### Gate 2：专用 PIC 信息压缩门

进入架构 A 设计/流片前，应先用离线完整光谱回答：

- 多少个滤波/投影通道足以保留目标信息；
- 对温度、偏振、批次和涂层老化是否仍可辨识；
- 选定滤波器的工艺偏差和热漂移容限；
- PD/TIA/ADC 的动态范围、噪声和功耗预算能否闭合；
- 相比现成模块/仪器，专用链的尺寸、功耗、成本或可访问性优势是否明确。

任一问题无证据时，先用可编程滤波器、台式器件或多通道采集模拟 PIC，不直接流片。

### Gate 3：联合或分叉决策

| 证据结果 | 决策 |
|---|---|
| 黑盒可访问且可辨识，专用 PIC 优势未证明 | 继续架构 B，建立应用与数据库 |
| 黑盒不可访问，但光谱可压缩且预算闭合 | 转向架构 A |
| 两者均可行 | 黑盒作为验证/应用平台，专用 PIC 作为小型化路线；使用同一标定数据集比较 |
| 两者均不可辨识 | 回到传感结构、参考通道或应用定义，不继续堆叠 DSP/流片 |

## 9. 建议的最小数据记录

```text
run_id, timestamp, architecture, hardware_revision, firmware_version,
sensor_id, coating_batch, reference_sensor_id,
target, target_truth, refractive_index_truth,
temperature, strain, bend_state, polarization_state, connector_state,
input_pattern, symbol_rate, wavelength_or_lane, launch_power,
pic_tuning_state, rx_gain_state, equalizer_state,
raw_pd_or_adc, rx_power, channel_features,
eye_metrics, llr_histogram, symbol_confusion,
pre_fec_ber, fec_corrections, alarms,
instrument_reference, calibration_id, model_version,
estimate, confidence, in_domain_flag, recovery_state
```

数据库必须保留原始值、配置、版本、参考真值和失败数据；不能只保存最终预测值。

## 10. 当前结论与下一动作

路线二不应预先在“专用 PIC”与“商用黑盒”之间二选一。更低风险的顺序是：

1. 用外部仪器和普通 FBG/未功能化 TFBG确认光学真值；
2. 用可访问的收发平台完成黑盒 `u → y/z` 可观测性与可辨识性测试；
3. 用完整光谱离线模拟少通道滤波/投影，判断专用 PIC 是否能保留足够信息；
4. 以相同传感头、扰动矩阵和留出数据比较两条架构；
5. 只有预算闭合并通过选择门，才进入 CPO 适配、专用 AFE/ADC 或 PIC 流片。

最需要优先取得的不是某个漂亮的灵敏度数字，而是四项边界证据：**哪些输入可控、哪些连续状态可读、主要干扰能否分离、映射能否跨批次和时间复现。**
