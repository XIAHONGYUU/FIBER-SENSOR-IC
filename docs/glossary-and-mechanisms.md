# 术语表与机制对照

本页统一仓库中的工程语言，避免把传感元件、解调方法、光子芯片和电子芯片混为一谈。定义用于本项目沟通，不替代标准或计量规范。

## 核心术语

| 术语 | 本仓库中的含义 | 容易混淆之处 |
|---|---|---|
| FBG | 光纤布拉格光栅；主要观察布拉格波长随温度、应变等变化 | “器件成熟”不表示小型化解调链已经成熟 |
| TFBG | 倾斜光纤布拉格光栅；倾斜栅面把芯模能量耦合到包层模 | 其折射率信息通常来自一组包层模，不是单一峰值 |
| DAS | 分布式声学传感；通常利用瑞利后向散射的相位/强度变化定位振动 | 与点式 FBG 的采样、相干性和算力需求不同 |
| PIC | 光子集成电路；在芯片上实现滤波、分束、干涉、调制或探测等光学功能 | PIC 不等同于 CMOS，也不自动包含激光器和 ADC |
| CMOS AFE | 用 CMOS 实现的模拟前端，如 PD 偏置、TIA、增益和滤波 | AFE 成立不表示传感机理或光学前端已经集成 |
| Interrogator | 给传感器提供光并从返回光中恢复被测量的解调系统 | 可以是机架、台式、板卡或芯片子系统，形态差异很大 |
| Wavelength tracking | 估计峰值或谱特征的波长变化 | 分辨率、精度、重复性和绝对准确度不能互换 |
| Feature compression | 把完整光谱压缩为少量差分、面积、包络或学习特征 | 压缩会丢失信息，需用任务指标验证 |
| Cross-sensitivity | 温度、应变、偏振、光功率等非目标变量对输出的影响 | 不能只用单次标定宣称已经消除 |
| Reference channel | 用于归一化、温漂补偿或仪器校准的参考信号通道 | 参考通道也有噪声和漂移，并非理想真值 |
| Co-packaging | 把光纤、PIC、电子芯片和必要光源/连接结构集成进同一封装体系 | 与“同一 PCB 上”或“同一仪器内”不是同一级别 |
| Qualification | 面向工作寿命、温度循环、湿热、机械和制造一致性的验证 | 论文演示、样机运行和量产资格是不同证据等级 |

## 机制对照

| 路线 | 主要被测量 | 原始光学观测量 | 常见解调 | 适合承担的角色 | 主要融合难点 |
|---|---|---|---|---|---|
| 普通 FBG | 温度、应变、振动 | 窄带反射峰波长 | 扫频、滤波边沿、AWG/MZI/微环、干涉或算法跟踪 | 基线、标定、参考通道 | 波长准确度、温漂、复用、光源和参考 |
| TFBG 折射率 | 外界折射率、表面结合事件及相关变量 | 多个包层模的幅度、位置、包络与偏振响应 | 高分辨率光谱、差分面积、包络导数、偏振差分、学习特征 | 主要融合创新 | 复杂光谱、偏振、温度、功能化表面和长期漂移 |
| DAS | 沿光纤分布的振动/动态应变 | 瑞利后向散射的相位或强度随距离和时间变化 | 相干探测、高速采集和分布式数字处理 | 远期系统扩展 | 激光相干性、动态范围、采样带宽、数据吞吐和算力 |
| 荧光光纤温度 | 温度 | 荧光强度、寿命或比率 | LED 激励、PD/TIA、同步或相关读出 | CMOS 接口邻近证据 | 机理不同，不能直接替代 FBG/TFBG 光谱解调 |

## 指标使用规则

- **分辨率**：最小可区分变化，必须同时说明带宽、滤波和统计口径。
- **准确度**：结果与可追溯参考之间的偏差，不能由曲线平滑度替代。
- **重复性**：同一条件下多次测量的一致性，不能代替跨温度和跨器件一致性。
- **灵敏度**：输出对被测量的局部斜率；高灵敏度不必然带来低检测限。
- **检测限**：必须结合噪声、漂移、时间窗和判定方法，不只引用斜率。
- **带宽/采样率**：电子采样率不等于有效测量带宽，光学扫描和数字处理都可能成为瓶颈。

所有数值指标将在 R2 的需求与误差预算中绑定测量条件、参考仪器和失败判据。
