# 技术主张与证据边界

## 状态定义

- **来源事实**：可定位到一级论文、标准、官方产品资料或可复现实验。
- **作者推导**：由多个来源推演出的系统判断，必须列出成立条件。
- **研究假设**：值得验证但尚无充分证据的路线。
- **待核对**：已发现线索，但书目信息、适用条件或原始数据尚未完成复核。
- **排除表述**：证据不足、容易误导或涉及未授权内容，不进入公开结论。

## 更新规则

1. 新主张先进入证据台账，再进入报告；
2. 论文中的器件原型不能自动升级为产业事实；
3. 官方产品资料支持“存在该产品”，不自动支持厂商未公开的内部架构；
4. 综述用于发现来源，关键结论应尽量回到原始论文；
5. 新证据与既有架构冲突时，优先修正架构。
