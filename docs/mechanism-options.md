# 光纤传感机制与芯片融合成熟度

## 判断维度

“机制成熟”和“芯片融合成熟”必须分开评价：

- 传感元件是否具有稳定机理和商品；
- 解调仪是否已经工业化；
- 光学解调是否进入 PIC；
- PD、AFE、ADC 和数字校准是否共同设计；
- 是否存在可量产、可封装和可维护的完整模组。

## 当前比较

| 机制 | 传感/产业成熟度 | 工业解调仪 | 芯片级融合 | 本项目角色 |
|---|---|---|---|---|
| 普通 FBG | 高 | 高 | 中，已有多种硅光原型 | 验证基线 |
| TFBG / LPG 折射率 | 学术较高、产业有限 | 中 | 低 | 主要创新 |
| Fabry–Perot / MZI | 高 | 高 | 中低 | 比较路线 |
| 荧光光纤 | 中、应用垂直 | 中 | 已有 CMOS 个案 | CMOS 读出证据 |
| DAS / DTS | 高 | 高，多为设备级 | 低到中、快速发展 | 远期扩展 |
| 片上微环生化传感 | 学术较高 | 不依赖传统光纤传感仪 | 较高 | 邻近领域，不作主线 |

## 为什么以普通 FBG 为基线

普通 FBG 的温度、应变和动态测量已有成熟参考仪器与标定方法，适合回答“集成读出有没有测对”，而不是同时承担敏感元件机理的不确定性。

其不足是传感原理和商业系统已经成熟，因此本项目不把“做一个 FBG 传感器”包装成新贡献；研究价值集中在解调链、电子接口、校准和封装。

## 为什么以 TFBG 为主要创新

TFBG 的包层模和表面功能化可对周围折射率敏感，但其梳状光谱、偏振依赖、温度交叉敏感和表面状态通常增加了解调复杂度。

主要问题是：能否把依赖高分辨率光谱的特征，压缩为少量可由光电探测器和 CMOS 处理的观测量，例如：

- 两个或多个固定波段的差分功率；
- 模式包络面积或质心；
- 参考光栅与敏感光栅的比值；
- 可调微环或 AWG 通道响应；
- 低分辨率光谱与数字特征提取联合解调。

## 为什么 DAS 只作远期扩展

DAS 产业系统已经成熟，但激光线宽、调制消光比、相干接收、高速采样和海量信号处理使其不适合作为首个最小验证对象。

本仓库后续关注的是其“设备级成熟、芯片级融合仍在推进”的矛盾，以及与通信共享光纤、频谱和接收机时的性能代价。
