# 初始光学—电学信号链

## FBG 验证基线

```text
稳定光源或扫频光源
→ 耦合/环行路径
→ FBG 反射谱
→ MZI / AWG / 微环 / 边缘滤波
→ 单路或差分光电探测器
→ TIA
→ PGA / 抗混叠滤波
→ ADC
→ 波长估计、温度补偿和状态记录
```

## TFBG 主要创新路线

```text
宽带或可调光源
→ 偏振与功率参考
→ TFBG 包层模 / SPR 光谱
→ 少通道滤波阵列或可调 PIC
→ 多路 PD 电流
→ 低噪声 TIA 与同步采样
→ 特征提取
→ 折射率估计 + 温度/功率/偏振补偿
```

## 首版预算字段

当前只定义字段，不填写未经来源支持的目标数值。

| 层级 | 必须登记的参数 |
|---|---|
| 敏感元件 | 中心波长、谱宽、反射/透射损耗、灵敏度、滞后、重复性、温度交叉敏感 |
| 光源 | 波长范围、线宽、RIN、输出功率、扫频速度、温漂 |
| PIC | 插入损耗、通道间隔、滤波斜率、热调谐效率、串扰、偏振依赖 |
| PD | 响应度、暗电流、带宽、结电容、匹配误差 |
| AFE | 输入电流范围、TIA 增益、噪声、带宽、线性、饱和恢复 |
| ADC | 输入范围、有效位数、采样率、通道同步、参考漂移 |
| 数字解调 | 估计偏差、更新时间、训练或标定依赖、异常检测 |
| 系统 | 功耗、尺寸、启动时间、温度范围、校准周期、参考仪器一致性 |

## 最小验证原则

1. 先以商用光谱仪或工业解调仪作为参考；
2. 同时采集参考仪器与候选电学链路；
3. 分别注入温度、应变、光功率和连接损耗扰动；
4. 只有候选链路能区分目标变化与主要干扰时，才进入 TFBG 折射率实验；
5. 失败结果必须保留，不通过调参隐藏不可辨识性。
