# 基于 CPO 黑盒电学指纹的功能化光纤连续传感

**版本：** v0.1 专家讨论稿  
**日期：** 2026-10-13  
**状态：** 作者构想 / 待专家评审 / 尚无实验结果

## 摘要

本文提出一种候选架构：不为功能化光纤另建完整的高分辨率光谱解调仪，而把共封装光学（CPO）或硅光收发链抽象为一个可控电输入—可观测电输出的黑盒光电系统。在发射端输入经过设计的通信或测试序列，使光信号通过普通 FBG、功能化 TFBG 或其他敏感光纤段；在接收端采集接收功率、模拟波形、软判决、均衡器状态、pre-FEC BER、误码结构和 FEC 纠错统计，建立传感状态与多维电学指纹之间的标定关系。

该方案的核心不是等待链路掉线，而是在通信仍可用时，从链路裕量和错误结构的连续变化中反演折射率、浓度或结合状态。进一步可主动改变码型、功率、波长、导频或符号统计，使 CPO 链路从被动通信通道变成主动系统辨识平台。

本文不声称现有 CPO 已具备该传感功能，也不声称误码能够唯一对应折射率。目标是向光纤传感、硅光、通信和集成电路专家确认：这一系统抽象是否成立、关键观测量是否可访问、哪些实验最先能够证伪或支持该路线。

## 1. 核心研究命题

> 能否只对 CPO 光路中的一段光纤进行功能化修饰，通过主动设计发送端电信号，并读取接收端已有或低成本增加的电学遥测，建立折射率等传感状态与连续电学指纹之间的可重复映射，从而减少对独立高分辨率光谱仪的依赖？

这一路线把系统写成：

```text
可控电输入 u(t)
      ↓
[CPO / 硅光 Tx：电 → 光]
      ↓
[功能化光纤：状态 x 改变光学信道 H]
      ↓
[CPO / 硅光 Rx：光 → 电]
      ↓
连续电学输出 y(t) 与数字软信息 z
```

形式化表示为：

```text
y(t), z = G[u(t), H(x, T, ε, P, b, a), φ]
```

其中：

- `x`：目标折射率、浓度、表面结合状态等；
- `T`：温度；`ε`：应变；`P`：偏振；`b`：弯折/连接状态；`a`：老化；
- `H`：功能化光纤形成的光学传递函数；
- `φ`：CPO 发射机、接收机、DSP 和控制环路的内部状态；
- `u(t)`：可设计的发送电序列；
- `y(t)`：模拟接收波形；`z`：遥测、软判决和误码特征。

目标是获得经过边界验证的估计器：

```text
x_hat = f[u(t), y(t), z, reference]
```

## 2. 为什么选择 CPO 黑盒抽象

CPO 本身不是光纤传感器。它的价值在于已经组织了高速电接口、光源或外部激光接口、硅光调制、光纤耦合、光电探测和数字通信链。OIF 的 CPO 框架将光引擎定义为 ASIC 与光信号之间的转换单元，并包含 PIC 和并行单模光纤接口；这支持“电输入—光纤信道—电输出”的系统抽象，但不证明任何具体 CPO 产品开放了所需内部数据。[OIF Co-Packaging Framework](https://www.oiforum.com/wp-content/uploads/OIF-Co-Packaging-FD-01.0.pdf)

该抽象带来三个潜在价值：

1. **复用既有光电链。** 初期研究可以避免重新设计完整的激光、调制、PD、TIA、ADC 和高速接口。
2. **电学接口可自动化。** 发送码型、接收统计和数据库采集更容易进入 FPGA、测试机或软件控制流程。
3. **从报警扩展到连续测量。** 数字链路最终只有正确/错误，但判决之前的接收功率、波形分布、软信息和链路裕量是连续量。

## 3. 从“掉线报警”到“连续电学指纹”

最简单的实现可以把链路状态当作一位传感器：正常状态通信，目标状态掉线。但这种输出不可定量，也很难区分目标物、温度、弯折、连接器和激光漂移。

更有价值的是在链路仍然可用时读取多层观测量：

| 层级 | 候选观测量 | 可能反映的信息 | 当前风险 |
|---|---|---|---|
| 模拟前端 | PD 电流、接收功率、TIA 幅度 | 总损耗、耦合和吸收 | 选择性弱，易受光源漂移影响 |
| 波形统计 | PAM4 电平中心/方差、眼高、眼宽、交叉点 | 非线性、噪声、码间干扰 | 商用 CPO 未必开放原始采样 |
| DSP 状态 | CTLE/FFE/DFE 系数、判决阈值、时钟相位 | 信道频响和自适应补偿量 | 控制环可能隐藏或混合传感变化 |
| 软信息 | LLR/置信度直方图、符号混淆矩阵 | 距离判决边界的连续裕量 | 需要 pre-FEC 或调试接口 |
| 链路质量 | eSNR、pre-FEC BER、FEC 纠错数 | 综合信号质量 | 多种干扰可能产生相似结果 |
| 系统状态 | lane degrade、告警、link down | 阈值事件 | 信息量最低且影响业务 |

CMIS 已定义 eSNR、pre-FEC BER、错误帧等性能监控量，C-CMIS 还定义了基于 pre-FEC BER 的链路退化监测。这说明标准化通信遥测能够提供部分电学观测量，但不能据此假设所有 CPO 平台都支持或开放相同字段。[CMIS 5.1](https://www.oiforum.com/wp-content/uploads/CMIS5p1_Third_Party_Spec.pdf)；[OIF C-CMIS 1.0](https://www.oiforum.com/wp-content/uploads/OIF-C-CMIS-01.0.pdf)

## 4. 为什么“误码类型”可能比 BER 更有信息

单一 BER 是大量物理变化的聚合结果。错误发生在哪些电平、哪些符号转移、哪些码型和哪些时间段，可能提供更丰富的光信道指纹。

| 电学指纹候选 | 待验证的可能解释 |
|---|---|
| PAM4 四个电平均同比压缩 | 整体插入损耗或接收功率下降 |
| 特定相邻电平混淆增加 | 非线性、消光比或判决阈值变化 |
| 长连零/连一后错误增加 | 低频响应、基线漂移或控制环效应 |
| 高频跳变时错误集中 | 带宽、频谱斜率或码间干扰变化 |
| 错误呈突发分布 | 偏振、反射、机械扰动或模式切换 |
| 某个 WDM lane 先恶化 | 传感谐振与该波长接近 |
| 均衡器抽头缓慢漂移 | 光电信道频率响应发生变化 |
| BER 不变但软置信度下降 | FEC 之前的链路裕量正在减少 |

这些对应关系目前都是待验证假设，不能只凭数据库相关性认定因果机制。

## 5. 主动设计发送信号

如果发送端只承载随机业务流，系统属于被动异常监测。若主动改变输入，问题可转化为受约束的系统辨识：选择最能区分目标状态与干扰状态的测试序列，同时限制通信性能代价。

| 可控输入 | 可能增强的可观测性 | 约束 |
|---|---|---|
| PRBS 阶数和重复周期 | 频率响应、记忆效应 | 需要固定且可重复的测试窗口 |
| PAM4 电平概率 | 不同光功率点的响应 | 可能改变平均功率和链路统计 |
| 符号跳变密度 | 带宽和码间干扰 | 与正常业务分布不同 |
| 发射功率微扰 | 线性度和损耗斜率 | 不得超过眼安全和器件限制 |
| 导频或多音信号 | 特定频段的信道变化 | 需要避免干扰业务 |
| 波长切换或热调谐 | 传感光谱不同位置 | CPO 激光/PIC 未必支持足够调谐范围 |
| 多个 WDM lane | 并行采样多个谱点 | lane 间工艺、功率和接收差异需校准 |

可将探测序列设计写成约束优化：

```text
选择 u*(t)，最大化目标状态可分性或 Fisher 信息
约束：BER、功耗、时延、平均光功率和业务中断均在允许范围内
```

## 6. 功能化 TFBG 的角色

普通 FBG 主要表现为反射峰移动，适合建立温度/应变基线。若固定通信载波不位于其光谱斜坡附近，波长变化未必能有效映射为接收电信号；过强反射还可能影响通信光路。

TFBG 可通过包层模与外界介质相互作用，其透射光谱的峰位、包络、偏振或损耗可随外界折射率和表面功能化状态变化。因此，候选映射为：

```text
目标物 / 折射率变化
→ TFBG 包层模或透射谱变化
→ 固定或多波长通信光的幅度、偏振、相位和频响变化
→ CPO 接收波形与软信息变化
→ 电学指纹反演
```

“有 TFBG 商品元件”和“低分辨率算法可提取 TFBG 特征”只能支持元件和方法邻近性，不能证明 CPO 黑盒路线已经成立。相关边界见本仓库 [证据台账](../evidence/evidence-ledger.csv) 中 E-004—E-006、E-016—E-021。

## 7. 数据库不是简单查表

建议的最小记录单位不是“浓度—BER”二元对，而是带完整条件的事件：

```text
{
  sensor_id, coating_batch, timestamp,
  target, concentration, refractive_index,
  temperature, strain, bend, polarization_state,
  wavelength_or_lane, launch_power, input_pattern,
  rx_power, level_centroids, level_variances,
  eye_metrics, equalizer_taps, llr_histogram,
  symbol_confusion, pre_fec_ber, fec_corrections,
  recovery_state, reference_lane, instrument_reference
}
```

若只使用固定波长，结果应称为“多激励电学指纹”，不宜称为完整光谱。只有经过波长扫描、多个 WDM lane 或滤波器组采样后，才可以讨论“电域敏感频谱”。

建模时必须区分：

- 训练/标定条件内的拟合；
- 跨温度、跨器件、跨封装和跨时间的泛化；
- 目标物与非目标扰动的可辨识性；
- 相关性与物理因果解释。

## 8. 最小验证方案

第一阶段不要求真正的商用 CPO。可以使用可读取接收遥测的硅光收发模块、光模块评估板或 FPGA 高速收发平台，验证黑盒输入输出关系。

```text
固定/可调激光与调制发送端
        ↓
普通 FBG 基线 / 功能化 TFBG 传感段
        ↓
高速接收机 + 可访问的 pre-FEC/软信息
        ↓
自动化激励、采集与标定数据库

并行参考：无修饰光纤或相同结构的非敏感参考 lane
外部真值：商用光谱仪/功率计 + 折射率或浓度参考
```

### 阶段 A：证明连续电学可观测性

1. 用普通可控衰减器代替传感器，验证各电学特征随光功率变化的分辨率、动态范围和重复性；
2. 串入普通 FBG，在温度或应变扫描中建立参考仪器与电学特征的对应；
3. 串入未功能化 TFBG，用标准折射率液体建立基础响应；
4. 比较固定业务码流和固定 PRBS 测试序列。

### 阶段 B：证明可辨识性

1. 独立扫描折射率、温度、弯折和偏振；
2. 建立敏感 lane 与参考 lane 的差分特征；
3. 使用留出的温度、器件和时间批次测试模型；
4. 检查是否存在不同物理状态产生相同电学指纹的退化情形。

### 阶段 C：证明主动激励价值

比较多种输入码型、功率和波长组合，验证主动激励是否相对于单一 BER 或单一接收功率显著提高灵敏度、选择性或抗干扰能力。

## 9. 通过与失败判据

### 最小通过条件

- 在链路保持通信且未触发 link down 的范围内，至少一种电学特征对目标状态呈连续、可重复、可恢复变化；
- 相比单一接收功率，加入主动激励或误码结构后显著提高目标状态与温度/弯折干扰的可分性；
- 在独立测试批次中仍能达到预先定义的反演误差，而不是只拟合训练数据；
- 参考 lane 能解释或消除一部分光源、温度和连接变化；
- 外部光谱或计量参考与电学反演结果具有可追溯对应。

### 应停止或重构路线的条件

- 只有完全掉线，没有可利用的连续前兆；
- 不同折射率、温度和弯折状态形成不可区分的电学特征；
- AGC、均衡、功率控制或 FEC 完全隐藏传感变化，且内部状态不可访问；
- 功能化光纤带来的固定损耗、反射或可靠性代价超过链路预算；
- 标定关系无法跨器件、跨时间或跨封装复现；
- 主动测试序列带来的通信代价高于获得的传感收益。

## 10. 与已有工作的边界

已有同纤感知通信研究证明通信和分布式感知可以共享光纤、波长和部分光电资源，但通常仍包含专门的散射检测、波形或联合 DSP。[Integrated sensing and communication in an optical fibre](https://www.nature.com/articles/s41377-022-01067-1)

本构想的候选差异不是笼统的“通信 + 传感”，而是以下组合：

1. 把商用或准商用 CPO/硅光收发链作为黑盒电—光—电测量平台；
2. 只在中间光纤段引入可替换的功能化传感结构；
3. 把误码结构、软判决和自适应 DSP 状态视为传感特征，而不只使用链路通断；
4. 主动优化发送电序列以增加可辨识性；
5. 通过参考 lane 和外部真值建立可校准的电学指纹数据库。

这些组合是否具有足够的新颖性，仍需进一步检索论文和专利；本文不作新颖性或可专利性结论。

## 11. 希望专家重点评价的问题

1. 将 CPO/硅光收发链抽象为稳定黑盒是否合理？哪些内部控制环会破坏可重复性？
2. 商用或研究级平台最现实可读取哪些 pre-FEC、软判决、均衡和波形统计？
3. TFBG 是否是最合适的中间敏感结构，还是 LPG、微锥、干涉型光纤或弱反射结构更适合通信链？
4. 固定波长、多 WDM lane 和可调激光三种路线中，哪一种最有可能首先形成可复现实验？
5. 哪些误码结构真正具有物理可解释性，哪些只会反映接收机自身实现？
6. 如何设计参考 lane，才能分离折射率、温度、偏振、弯折和连接器漂移？
7. 初期应选择何种传感对象，既容易获得可靠真值，又能体现表面功能化价值？
8. 该方向已有工作和专利中，哪些与“主动通信激励 + 电学指纹反演 + CPO 黑盒”最接近？

## 12. 当前结论

该构想在系统层面具有可行的物理链路和可验证的最小实验，但其价值取决于三个尚未证明的前提：接收端连续特征是否可访问、目标状态是否可从干扰中辨识、功能化光纤是否能在通信链路预算内产生稳定响应。

因此，下一步不应立即设计专用芯片，而应先用可访问的收发平台完成“可观测性—可辨识性—主动激励增益”三项验证。只有三项均成立，才进入 CPO 适配、专用监测电路或共封装实现。
